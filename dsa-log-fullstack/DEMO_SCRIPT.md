# Demo video checklist (about 2 minutes, screen recording)

Use Windows Game Bar (Win + G) or OBS. Say what you are doing out loud.

1. Show the terminal: `npm start` running in `server/` and the message "DSA Log app running on http://localhost:3000".
2. Open http://localhost:3000, click Sign in, create an account (try a weak password first to show the validation message).
3. Dashboard: show the 6 topics and the stats. Search "arr". Use a status filter. Add a new topic.
4. Open the Arrays topic: tick two problems, show the progress bar change, add a problem, write a note.
5. Refresh the page to show the data is saved. Go back to the dashboard and show the stats updated.
6. Log out, then try opening dashboard.html to show it redirects to the login page.
7. Show `npm test` in the terminal with all tests passing.
8. Optional: stop the server and click something to show the "Cannot reach the server" message.
